This website

This site collects no personal information from anyone, including children. It sets no cookies and runs no analytics, ads or tracking. It loads nothing from other companies: no fonts, scripts or embedded videos. Its only script fills in the year at the bottom of the page.

The site is hosted by GitHub Pages. Like any web host, GitHub logs the IP address of each visit for security purposes. We don't see those logs. GitHub explains what it does with them in the GitHub General Privacy Statement.

When you email us

If you write to support@calastudios.app, we receive your email address and your message. We use them only to answer you. We never add you to a mailing list and never sell or share what you send. Ask us to delete your messages and we will.

Changes

If this policy changes, we'll update it here and change the date at the top.
